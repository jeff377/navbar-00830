# ADR 0001:計算層與呈現層徹底分離

- 狀態:已採用
- 日期:2026-07-07

## 背景

工具要顯示 00830 盤後重估淨值與折溢價。呈現形式(選單列 / 網頁 / iOS Widget)未來可能變,但淨值計算、時序判斷、資料源邏輯不該跟著改。

## 決策

分三層,依賴單向由上而下:

- **NAV830Core**:純計算(重估、折溢價、去槓桿、時序狀態機、行事曆)。**只依賴 `Foundation`**,不碰 UI、不碰網路型別。
- **NAV830Fetch**:資料源實作,依賴 Core + `Foundation`/URLSession;可注入 `HTTPClient` 以離線測試。
- **NAV830App**(殼):平台專屬呈現,依賴前兩層。

Core 對抓取層/呈現層**零依賴**,由 SPM 模組邊界結構性保證(不是靠自律)。

## 結果

- ✅ 換殼不動核心:macOS 選單列可換成 iOS App/Widget,Core+Fetch 原封不動重用(見 [0004](0004-macos-選單列殼.md)、`plans/01-ios-支援.md`)。
- ✅ Core 可用固定 fixture 做確定性單元測試(過 §附錄 sanity check),不需網路。
- ✅ 資料源可個別抽換、加 fallback,不影響計算。
- ⚠️ 代價:多了模組邊界與 protocol 抽象;對這麼小的工具值得,因為呈現層確定會多平台。

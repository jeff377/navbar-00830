# ADR 0003:資料源選型

- 狀態:已採用
- 日期:2026-07-08(實測定案)

## 背景

四類輸入:官方淨值、00830 市價、美股半導體代理盤後、匯率。需免費、免金鑰、穩定、可離線測試。

## 決策

| 輸入 | 採用 | 端點 |
|---|---|---|
| 官方淨值 + 市價 + 官方估值 | **Cathay(單一來源,一次抓)** | `cwapi.cathaysite.com.tw/api/ETF/GetRealTimeEstimateNavList` |
| SOXX/SOXQ/SOXL 盤後 | **Nasdaq** | `api.nasdaq.com/api/quote/{S}/info` + `.../extended-trading?markettype=post` |

- 淨值、市價同一筆(`closingNav`/`estimateNav`/`lastPrice`)→ 一個 `CathayETFSource.fetch()` 拿齊,不重複抓 ~90KB。
- SOXX 為主,SOXQ/SOXL 交叉;`FallbackProxySource` 降級。

> **已由 [ADR 0005](0005-以-sox-指數為主要代理.md) 取代(2026-08-06)**:SOXX 與 SOXL 追的不是 00830 的
> 標的指數,主代理改為 SOX 指數本身(`assetclass=index`),偏好序 `SOX → SOXQ → SOXX → SOXL`。

### 淘汰的來源(實測不可用/多餘)

- **Yahoo Finance**:query1/query2 皆 429 IP 封鎖。→ 改 Nasdaq。
- **台銀匯率 CSV**:bot-challenge JS 牆。→ 一度改 open.er-api。
- **open.er-api FX**:後來發現 `estimateNav` 已內含官方匯率,自算會重複 → **整個移除**(見 [0002](0002-重估模型.md))。
- **TWSE MIS**:盤中 `z`(成交價)常回 `"-"`,要靠買賣中價/昨收 fallback;且改用 Cathay `lastPrice`(對齊官網)後 **整條移除**。

## 結果

- ✅ 兩個外部主機(Cathay、Nasdaq),數字對齊國泰官網。
- ✅ 每個 parser 對實錄 fixture 離線測試;`NAV830_LIVE=1` gated live smoke test。
- ⚠️ 全靠 Cathay 提供淨值+市價 → Cathay 掛則無 report(但淨值本就無替代源,不算新增風險)。
- ⚠️ Nasdaq/Cathay 皆非官方 API,格式可能變;有防呆(盤後偏離收盤 >30%×槓桿則忽略)與 fixture 回歸測試把關。
